# Gridiron Life v0.601 — Mini Changes Consolidation

Built on the complete v0.61 History & Growth update plus the Story Details Hotfix.

## Changes
- Header quick indicators now show **Stress, GPA, Fatigue, and Morale**, instead of duplicating Speed, Strength, Contact Balance, and Vision.
- Fatigue indicator uses the **higher** of the existing physical or mental fatigue values. Both individual readings remain on the Development screen.
- GPA uses college GPA during college; at NFL stage the GPA tile changes to **Role** (Camp / Practice / Backup / Starter).
- The four indicator cards stay centered and compact above the fixed bottom navigation.
- Story Opportunity Open details and other Hub detail dialogs keep the prior hotfix behavior.
- High-school District Standings now shows **HS Index** instead of ambiguous STR. This is a **display-only** scaled program index (rounded 65% of the previous internal simulation strength); it is NOT comparable to a player's high school, college, or NFL OVR. It does not rebalance game outcomes or change underlying school ratings. Across-league absolute ratings remain future work.
- In-game display and page title now read **v0.601**.

## Compatibility
The existing `gridiron-life-v6` browser save slot is unchanged. Back up via Save / Export before installing. Existing v0.61 careers should continue with the modified HUD.
