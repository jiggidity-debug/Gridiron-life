# v0.602 — Creator cleanup (CLEAN-CREATOR-1)

Root issue: Two character creation implementations shipped simultaneously: an obsolete 100-point setup in `30-creation.js` / `70-ui.js`, plus the newer 300-point, family/history creator in `74-part9.js`. The latter normally overrides the older one, but this left contradictory rules and avoidable regression risk.

This build retires the obsolete form/start code, preserving required school selection helpers. `74-part9.js` is now the sole character-creation implementation. The existing physical baselines continue to be halved: 155-lb RB Speed 23, 300-lb RB Speed 3, 200–219-lb RB Speed 22. Historical base 45 or 5 cannot be generated by this creator.

Creation rules: 300 allocated points; Athletic and Technical allocation may take base+points up to 70 before family/history; parent and history bonuses are applied afterward, up to 99. Personal has zero baseline.

The registration header displays `v0.602 · CLEAN-CREATOR-1` to make deployment diagnosis unambiguous. New query version for every JS/CSS resource in `index.html` avoids stale-file reuse when index and JS are uploaded together.
